## Project Overview

MoonDex is a Unity 6000.2.14f1 project that uses the Universal Render Pipeline (URP). It depends on the external `com.digimbyte.core` framework for asset management and core systems.

## Core Framework Dependency

This project uses the `com.digimbyte.core` framework (https://github.com/digimbyte/core-framework.git) which provides:

### Asset Registry System
The Core framework provides a type-safe asset management system. All asset instantiation uses the Registry pattern:

**Asset Loading Pattern:**
```csharp
using Core.Registry;

// Get prefabs using GetPrefab(uid) - has built-in error handling
var manager = RegistryManager.Instance;
GameObject prefab = manager.GetPrefabByUID("registry_name/item_uid");

// Use composite keys format: "registryName/itemUID"
GameObject enemy = manager.GetPrefabByUID("enemies/goblin_warrior");
Texture icon = manager.GetTextureByUID("ui/icon_sword");
Material mat = manager.GetMaterialByUID("materials/metal_rusty");
```

**IMPORTANT:** Use `GetPrefab(key)` exclusively for instantiation. Do NOT use `GetRegistryDefaultPrefab`. GetPrefab(key) includes built-in error handling and is used blindly for instantiation.

**Object Pooling:**
```csharp
var integration = RegistryIntegration.Instance;

// Spawn from pool
GameObject instance = integration.Spawn("enemies/goblin", position, rotation);

// Return to pool
integration.Despawn(instance);

// Pre-warm pools
integration.PreWarmPool("enemies/goblin", 20);
```

### Coordinate System
This project uses **QR axial coordinates exclusively** for hexagonal grids. DO NOT use or introduce UV coordinates anywhere in the codebase.

## Unity Commands

Unity 6000 uses command-line batch mode for automation. Commands must be run from the Unity installation directory or with full path to Unity.exe.

**Common Unity CLI patterns:**
```powershell
# Open project in Unity Editor
& "C:\Program Files\Unity\Hub\Editor\6000.2.14f1\Editor\Unity.exe" -projectPath "P:\ToTheMoon\MoonDex"

# Build project (example for Windows)
& "C:\Program Files\Unity\Hub\Editor\6000.2.14f1\Editor\Unity.exe" -quit -batchmode -projectPath "P:\ToTheMoon\MoonDex" -buildWindows64Player "builds/MoonDex.exe"

# Run tests
& "C:\Program Files\Unity\Hub\Editor\6000.2.14f1\Editor\Unity.exe" -runTests -batchmode -projectPath "P:\ToTheMoon\MoonDex" -testResults TestResults.xml
```

**Note:** Unity does not have a traditional "build" command like npm or dotnet. The .csproj and .sln files are auto-generated by Unity and should not be committed to git.

## Architecture Notes

### Core Systems

**Registry Singleton Pattern:**
- `RegistrySingleton` (Assets/data/RegistrySIngleton.cs) provides singleton access to all registries
- Access via `RegistrySingleton.Instance`
- Pre-configured registries: Icons, Prefabs, Materials, Meshes, Audio
- Use `GetIcon(uid)` helper method for quick texture access
- Singleton is persistent across scenes (DontDestroyOnLoad)

**Radial Menu System (YAML-driven UI):**
- `RadialMenuFromYaml` (Assets/data/RadialMenuFromYaml.cs) - Main component that builds 3D radial menus from YAML data
- `RadialWedgeMeshTool` (Assets/UI/RadialWedgeMesh.cs) - Static tool for procedural wedge mesh generation
- `IRadialMenuItemHost` interface - Implement this on prefabs to receive menu item data
- Menu data stored in YAML format (Assets/data/database.yaml)
- Supports hierarchical menus with weighted item sizing
- Menu items are instantiated from a prefab root with procedurally generated wedge meshes
- Navigation: `Open(node)` and `Back()` methods for menu traversal

**Billboard System:**
- `Billboard` (Assets/Scripts/Billboard.cs) - Camera-facing sprite/quad component
- `BillboardRenderController` - Manages billboard rendering
- Modes: ScreenAligned, ViewpointOriented, WorldUpLockedYaw, TrueScreenSpace
- TrueScreenSpace mode provides perspective-corrected 2D appearance (eliminates distortion)

**Animation System (Custom Tween):**
- Located in Assets/Scripts/Animator/
- `TweenDirector`, `TweenAsset`, `TweenBindings` - Core tween animation components
- `Animate` helper for quick animations
- `Typer` for text typing effects
- Editor tools: TweenBoardWindow, TweenAssetInspector

### YAML Menu Data Structure
Menu items are defined in YAML with hierarchical structure:
```yaml
items:
  - id: category_id
    label: Display Name
    weight: 4  # Relative size in radial menu
    children:
      - id: sub_item
        label: Sub Item Name
        weight: 2
```

### Third-Party Systems

- **Gaskellgames** (Assets/Gaskellgames/) - Camera system, Input events, Core utilities
- **TotalJSON** (Assets/TotalJSON/) - JSON parsing library
- **Nova** (if present) - Additional UI framework

### When Adding Custom Code
- Create organized folder structure under `Assets/Scripts/`
- No namespace is used in current custom scripts (follow existing pattern)
- Follow Unity component-based architecture (MonoBehaviour for game objects)
- Use ScriptableObjects for data containers (see Assets/data/*.asset files)
- For radial menu items, implement `IRadialMenuItemHost` interface
- Register assets through the Core Registry system via RegistrySingleton
